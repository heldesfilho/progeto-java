# Projetos em Java

Este repositório consolida diversas aplicações, sistemas e componentes de software desenvolvidos utilizando a linguagem Java. O foco destas implementações abrange desde fundamentos da linguagem até a aplicação de padrões de projeto, arquitetura de software e integração com bancos de dados.


## Estrutura do Repositório

Cada diretório neste repositório representa um projeto isolado com seu próprio escopo e contexto técnico.

* biblioteca: Sistema de gerenciamento de biblioteca com integração a banco de dados MySQL para persistência e manipulação de registros.
* lista_de_tarefa: Aplicação simples de gerenciamento de tarefas desenvolvida para aplicar conceitos e estruturas fundamentais da linguagem Java.
